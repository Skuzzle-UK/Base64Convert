# Base64 Convert

A simple application in .NET MAUI, initially written to give a GUI encoding strings into base64 but expanded to allow encoding and decoding of strings and images.
It has become a really useful tool for my daily workflow so I have made it available to the public to make use of.

Provided at the repo root is a powershell script to simplify installing the app in windows. Being .NET MAUI it will most likely build fine for Android and can be easily adapted for MAC.

```
powershell -File install.ps1
```
